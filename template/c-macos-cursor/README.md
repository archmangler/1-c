# PROJECT_NAME

Minimal C project scaffold for Cursor on macOS (Clang + Make + LLDB).

See [SETUP.md](SETUP.md) for toolchain, extensions, build, and debug instructions.

## Quick commands

```bash
make        # build
make run    # build and run
make clean  # remove binaries
```

In Cursor: `Cmd+Shift+B` to build, `F5` to debug (requires CodeLLDB).
